# ELEVATE
Έξυπνοι ανελκυστήρες με προεπιλογή προορισμού, για πολυώροφο εταιρικό κτίριο.
Ομάδα «Στο παρά 8», Τμήμα Διοικητικής Επιστήμης και Τεχνολογίας, ΟΠΑ.
Ο εργαζόμενος δηλώνει όροφο και προορισμό. Το σύστημα διαλέγει τον κοντινότερο
ελεύθερο ανελκυστήρα. Σε συναγερμό οι καμπίνες βγαίνουν από διαθεσιμότητα.
## Φάκελοι
| Φάκελος | Τι περιέχει |
| ---| --- |
| `db` | Σχήμα PostgreSQL, μοντέλα, σύνδεση με Supabase, αποθετήριο |
| `core` | Αλγόριθμος ανάθεσης: ο κοντινότερος ελεύθερος ανελκυστήρας |
| `api` | REST για κλήσεις, ανελκυστήρες και έκτακτη ανάγκη. CLI αξιολόγησης |
| `app` | Οθόνη εργαζομένου, οθόνη διαχειριστή, CLI και παράθυρο συναγερμού |
## Απαιτήσεις
Java 17 και Maven. Για τις οθόνες, Node.js.
## Έλεγχοι
Από τον φάκελο κάθε module:
```bash
cd db
mvn test
cd ../core
mvn test
```
## Βάση
Οι ρυθμίσεις μένουν στον υπολογιστή σου, στο `db/src/main/resources/db.properties`.
Το αρχείο είναι στο `.gitignore` και δεν ανεβαίνει.
