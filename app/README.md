#  Φάκελος app (Η Βιτρίνα)
Εδώ φτιάχνουμε την εικόνα του συστήματος, δηλαδή αυτό που βλέπει και αγγίζει ο χρήστης:
- Σχεδιασμός της οθόνης
- Φτιάχνουμε τα κουμπιά όπου ο υπάλληλος θα πατάει τον όροφο που θέλει να πάει
- Φτιάχνουμε την οθόνη του διαχειριστή που θα βλέπει πού βρίσκεται το κάθε ασανσέρ εκείνη τη στιγμή
