# Φάκελος api (Η Γέφυρα)
Εδώ στήνουμε την επικοινωνία μεταξύ των παραπάνω φακέλων (μέσω REST).
Το API είναι σαν τον μεταφραστή ή τον ταχυδρόμο. Όταν κάποιος πατάει το κουμπί στο κινητό του (στο app):
- το API παίρνει αυτό το μήνυμα,
- το μεταφέρει στον εγκέφαλο (core) για να βρει λύση,
- και μετά επιστρέφει την απάντηση στην οθόνη του χρήστη.
