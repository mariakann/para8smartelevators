Elevate, REST API contracts
1. Σκοπός:
Το REST API του Elevate αποτελεί το μέσο επικοινωνίας μεταξύ της εφαρμογής χρήστη, του κεντρικού συστήματος ελέγχου και των ανελκυστήρων. Μέσω του API ο χρήστης υποβάλλει ένα αίτημα μετακίνησης και το κεντρικό σύστημα επιστρέφει το αναγνωριστικό του ανελκυστήρα που θα τον εξυπηρετήσει. Παράλληλα το κεντρικό σύστημα στέλνει εντολές στους ανελκυστήρες και λαμβάνει πληροφορίες για τη θέση και την κατάστασή τους.

2. Client API:
Το Client API είναι υπεύθυνο για την επικοινωνία μεταξύ της εφαρμογής χρήστη και του κεντρικού συστήματος ELEVATE.

2.1 Υποβολή αιτήματος μετακίνησης:
Όταν ένας χρήστης θέλει να χρησιμοποιήσει τον ανελκυστήρα αρχικά επιλέγει τον όροφο προορισμού του. Ο όροφος αφετηρίας είναι γνωστός από τη συσκευή του ορόφου ή δίνεται ως παράμετρος κατά την εκκίνηση της εφαρμογής γραμμής εντολών. Η εφαρμογή στέλνει στο κεντρικό σύστημα τον όροφο αφετηρίας, τον προορισμό και την προτεραιότητα του αιτήματος.

Τεχνικά στοιχεία:
HTTP Method: POST
Endpoint: /api/ride-requests
origin: Ο όροφος αφετηρίας (υποχρεωτικό, ακέραιος αριθμός)
destination: Ο όροφος προορισμού (υποχρεωτικό, ακέραιος αριθμός)
priority: Η προτεραιότητα του αιτήματος (υποχρεωτικό, ακέραιος αριθμός)
Οι τιμές προτεραιότητας είναι 1 για Emergency, 2 για Meeting και 3 για Normal, όπως ορίζονται στην κλάση RideRequest της ομάδας. Τα πεδία αυτά αντιστοιχούν στα originFloor, destinationFloor και priorityLevel που χρησιμοποιεί εσωτερικά η ίδια κλάση.

2.2 Απάντηση αιτήματος μετακίνησης:
Το κεντρικό σύστημα επιστρέφει μέσω του REST API το αναγνωριστικό του ανελκυστήρα που θα εξυπηρετήσει τον χρήστη. Στο συγκεκριμένο στάδιο της εργασίας χρησιμοποιείται μια σταθερή δοκιμαστική απάντηση, σύμφωνα με τις οδηγίες της ομάδας.
Το αναγνωριστικό επιστρέφεται ως κείμενο, σύμφωνα με τον τύπο του πεδίου id στην κλάση Elevator.

Στοιχεία απάντησης:
HTTP Response: 200 OK
elevatorId: Το αναγνωριστικό του ανελκυστήρα. Η διεπαφή χρήστη εμφανίζει το αναγνωριστικό γράμμα του.
Παράδειγμα δοκιμαστικής απάντησης:
{"elevatorId":"A"}

2.3 Διαχείριση λανθασμένων αιτημάτων:
Το Client API ελέγχει αν το αίτημα περιέχει τα απαραίτητα στοιχεία και αν οι τιμές τους είναι σωστές. Οι όροφοι πρέπει να βρίσκονται μέσα στα όρια του κτιρίου και ο όροφος αφετηρίας πρέπει να διαφέρει από τον όροφο προορισμού. Η προτεραιότητα πρέπει να έχει μία από τις τιμές 1, 2 ή 3.
Αν το αίτημα είναι λανθασμένο, το API το απορρίπτει και επιστρέφει μήνυμα σφάλματος.

3. Elevator API:
Το Elevator API είναι υπεύθυνο για την επικοινωνία μεταξύ του κεντρικού συστήματος ELEVATE και των ανελκυστήρων. Το κεντρικό σύστημα αποστέλλει εντολές, ενώ οι ανελκυστήρες ενημερώνουν για την τρέχουσα θέση, την κατάσταση λειτουργίας και τις επόμενες στάσεις τους.

3.1 Αποστολή εντολών στους ανελκυστήρες:
Το κεντρικό σύστημα στέλνει στον κατάλληλο ανελκυστήρα τη λίστα με τις στάσεις που πρέπει να ακολουθήσει. Η λίστα περιέχει τους ορόφους με τη σειρά που πρέπει να εξυπηρετηθούν.

Τεχνικά στοιχεία:
HTTP Method: POST
Endpoint: /api/elevators/{elevatorId}/commands
elevatorId: Το αναγνωριστικό του ανελκυστήρα στον οποίο απευθύνεται η εντολή (υποχρεωτικό, κείμενο)
stops: Η λίστα με τις προγραμματισμένες στάσεις (υποχρεωτικό, λίστα ακεραίων)
Το elevatorId περιλαμβάνεται στη διεύθυνση του endpoint, ενώ η λίστα stops αποστέλλεται σε μορφή JSON.

Απάντηση:
Ο παραλήπτης επιβεβαιώνει ότι έλαβε την εντολή, όμως η επιβεβαίωση παραλαβής δεν σημαίνει ότι ο ανελκυστήρας ολοκλήρωσε τη διαδρομή.

3.2 Ενημέρωση θέσης και κατάστασης ανελκυστήρων:
Κάθε ανελκυστήρας στέλνει στο κεντρικό σύστημα την τρέχουσα θέση και την κατάστασή του καθώς και τις επόμενες προγραμματισμένες στάσεις του. Οι πληροφορίες αυτές επιτρέπουν στο κεντρικό σύστημα να γνωρίζει την κατάσταση των ανελκυστήρων.

Τεχνικά στοιχεία:
HTTP Method: POST
Endpoint: /api/elevators/{elevatorId}/status
elevatorId: Το αναγνωριστικό του ανελκυστήρα (υποχρεωτικό, κείμενο)
currentFloor: Ο τρέχων όροφος του ανελκυστήρα (υποχρεωτικό, ακέραιος αριθμός)
status: Η κατάσταση λειτουργίας του ανελκυστήρα (υποχρεωτικό, κείμενο, π.χ. IDLE, όπως στην κλάση Elevator)
nextStops: Οι επόμενες προγραμματισμένες στάσεις (λίστα ακεραίων)
Το elevatorId περιλαμβάνεται στη διεύθυνση του endpoint, ενώ τα στοιχεία της κατάστασης αποστέλλονται σε μορφή JSON.

Απάντηση:
Το REST API επιβεβαιώνει ότι παρέλαβε την ενημέρωση

3.3 Διαχείριση λανθασμένων εντολών και ενημερώσεων:
Το Elevator API ελέγχει αν οι εντολές και οι ενημερώσεις περιέχουν τις απαραίτητες πληροφορίες. Αν λείπει κάποιο στοιχείο, αν ένας όροφος είναι εκτός των ορίων του κτιρίου ή αν τα δεδομένα έχουν λανθασμένη μορφή, το αίτημα απορρίπτεται και επιστρέφεται μήνυμα σφάλματος.
